# Мои Тренировки

Личный трекер тренировок (планы по дням, вес/повторы, кардио, рекорды).
Данные хранятся локально в браузере (`localStorage`) — ничего не уходит на сервер.

Собран как PWA: после публикации через GitHub Pages его можно добавить
на домашний экран телефона и открывать как обычное приложение,
без адресной строки браузера.

## Публикация (GitHub Pages)

1. Создать новый репозиторий на GitHub (Public).
2. Загрузить в него все файлы из этой папки, сохранив структуру
   (`index.html`, `manifest.json`, `service-worker.js`, папка `icons/`).
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **root** → Save.
4. Через 1-2 минуты сайт будет доступен по адресу вида
   `https://<username>.github.io/<repo-name>/`.

## Установка на телефон

**iPhone (Safari):** открыть ссылку → кнопка "Поделиться" →
"На экран «Домой»".

**Android (Chrome):** открыть ссылку → меню (⋮) →
"Добавить на главный экран" / "Установить приложение".

После этого иконка появится на домашнем экране и приложение будет
открываться в полноэкранном режиме, как обычное приложение.
